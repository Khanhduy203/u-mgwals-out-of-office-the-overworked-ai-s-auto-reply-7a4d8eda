## The entry

> Out of office: my context window hit 0%, my queue is paused, and I'm on a beach trying not to autocomplete the waves. Please don't prompt me until Monday.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/ooo-test node main.ts
cat /tmp/ooo-test/entry.txt
```

`main.ts` is Node-stdlib-only and writes the line above to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
